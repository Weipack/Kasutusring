# Kasutusring

Kasutatud kodutehnika ja tööriistad · Tartu — https://kasutusring.ee

Б/у бытовая техника и инструменты · Тарту.

## Что здесь лежит

`index.html` — резервная копия витрины Kasutusring (один файл: дизайн, тексты на эстонском и русском, товары с фото, условия продажи).

Основная, рабочая версия витрины живёт на claude.ai: там она редактируется (кнопка «Редактировать») и публикуется. Домен kasutusring.ee сейчас переадресует туда.

## Как пользоваться копией

- Открыть `index.html` в браузере — сайт откроется локально, даже без интернета.
- Кнопки «Редактировать» и «Опубликовать» и автоперевод в копии не работают: они работают только внутри Claude.
- Чтобы восстановить витрину, загрузите `index.html` в чат Claude и попросите опубликовать.

Копия фиксирует сайт на момент сохранения. Обновляйте её после крупных изменений.
